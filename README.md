# FYNZO Mobile App

This is a mobile-first Progressive Web App (PWA), designed to install on Android/iPhone from a browser.

Features:
- Standalone app-like interface
- Home / Saved / Settings navigation
- 117k+ local English word index
- Offline word recognition
- Installable PWA manifest
- Service-worker offline shell
- Saved vocabulary
- Pronunciation
- Dark/light theme
- Touch-first responsive UI
- Definitions fetched and cached when online

### Install
Serve this folder from HTTPS (or localhost for testing), open it in a mobile browser, then choose "Install app" / "Add to Home Screen".

Opening index.html directly still works for the dictionary UI, but browser install/PWA features require a secure origin such as HTTPS or localhost.
